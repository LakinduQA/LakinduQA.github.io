## Quality Engineering Projects

### Medusa.js UI and API Automation Framework

- Repository: [View repository](https://github.com/LakinduQA/medusa_automation_framework)
- Category: Test automation
- Tags: Playwright, Python, pytest, API, CI/CD

A Python-based quality engineering framework for automating Medusa.js storefront, Admin, and API workflows using Playwright and pytest.

Built around reusable Page Objects, shared fixtures, environment-driven configuration, and centralized API clients, with GitHub Actions validation, Allure and JUnit reporting, failure screenshots, Playwright traces, and repository-scoped agent skills supporting test assessment, authoring, review, and failure investigation.

## Development Projects

### EcoChain MVP

- Repository: [View repository](https://github.com/LakinduQA/ecochain-mvp)
- Category: Full-stack development
- Tags: React, Node.js, Express, Socket.io, Prisma, Docker

A full-stack MVP for a real-time food rescue marketplace connecting food donors such as retailers, bakeries, and restaurants with charities and food banks.

The platform supports role-based authentication, surplus food listings, real-time availability updates, instant claiming, and donation status tracking. It was built using React, Node.js, Express, Socket.io, Prisma, and a containerized development setup.

### Spendly — Personal Finance Tracker

- Repository: [View repository](https://github.com/LakinduQA/spendly-finance_tracker)
- Category: Full-stack development
- Tags: Python, Flask, SQLite, Oracle, SQL

A full-stack personal finance management system for tracking expenses, income, budgets, savings goals, and financial reports.
